# 爵士贝斯练琴助手 v2 — 设计文档

## 概述

在现有"爵士贝斯练琴助手"（日历打卡 + 练琴计划 + 基础统计）之上，新增三个功能：节拍器、六维游戏化评分系统、全站像素RPG画风。

---

## 一、节拍器

### 功能
- BPM 范围：20–250，滑块+手动输入
- 细分：四分音符、八分音符、十六分音符、三连音
- 重音模式：第1拍重音 / 第2&4拍重音（爵士模式）
- 声音：Web Audio API OscillatorNode 生成 click 音，重音拍音高略高
- 视觉：中心脉冲圆 + 四盏指示灯，重音拍颜色不同
- Tap Tempo：连点测速
- 声音/视觉独立开关复选框
- START/STOP 大按钮

### 技术
- 使用 `AudioContext` + `OscillatorNode` + `GainNode` 生成短促音效
- 使用 `setInterval` 或 `requestAnimationFrame` 驱动视觉脉冲
- 注意 AudioContext 需要在用户手势后 resume（浏览器限制）

### UI 布局
- 位于新导航项"节拍器"页面
- 大号BPM数字居中，下方滑块
- 细分/重音模式切换按钮组
- 声音/视觉复选框
- 底部 START/STOP + TAP 按钮

## 二、六维游戏化评分系统

### 六大维度
1. 技术基本功
2. 节奏/时值感
3. 听力（耳力）
4. 和声/乐理
5. 即兴/创造力
6. 曲库/实战

### 等级体系
每个维度三级：初级(I/II/III) → 中级(I/II/III) → 高级(I/II/III)

升级阈值（累加）：
- 初级I→II：300 XP
- 初级II→III：400 XP
- 初级III→中级I：600 XP
- 中级I→II：800 XP
- 中级II→III：1000 XP
- 中级III→高级I：1500 XP

### 经验公式
```
获得XP = 基础XP × 时长系数 × 段位衰减 × 自评系数
```
- 基础XP：由练琴标签自动匹配
- 时长系数：分钟/30
- 段位衰减：高级段位时 ×0.6
- 自评系数：自评分数/5

### 练琴标签 → 维度权重

| 标签 | 影响维度 |
|------|----------|
| 琶音/音阶 | 技术+6, 和声+2 |
| Walking Bass | 技术+2, 节奏+3, 即兴+2, 曲库+1 |
| 扒谱/练耳 | 听力+6, 曲库+2 |
| 节拍器/节奏 | 节奏+6 |
| 即兴/Solo | 即兴+5, 技术+2 |
| 乐理/和声 | 和声+6 |
| 曲目跟弹 | 曲库+4, 节奏+2, 即兴+1 |
| 手指/技巧 | 技术+5 |

### 衰减机制
- 某维度超过5天未练习，每天掉 2% 当前经验
- 最低掉到当前等级的底线（不降级，但经验条缩水）

### 客观参照系（行为锚定 + 标杆曲目）
每个维度的每个等级附带：
- 可验证的行为标准（如"节拍器80bpm附点节奏连续8小节"）
- 标杆曲目/乐手参照

参照表在结算页面和统计页面均可查看。

### 每日练琴打卡增强
在现有打卡弹窗中增加：
- 练琴标签多选
- 六维自评分数（1-10滑条）
- 保存时自动计算经验值

## 三、练琴结算画面（三层反馈）

### 第一屏：简洁总结
- 本次获得各维度XP列表 + 总XP
- 像素风格边框，快速概览

### 第二屏：RPG动画
- 六条经验条逐个动画增长
- 满条时触发"LEVEL UP!"弹窗
- 像素贝斯手角色沿路行走
- 可选的8-bit音效

### 第三屏：智能建议
- 基于近期练习数据和衰减状态生成一句话建议
- 示例："节奏快升中级I了，集中练！"/ "和声已5天未练，小心衰减"

## 四、像素RPG画风（全站改造）

### 参考风格
- 星露谷物语 (Stardew Valley)
- 复古16-bit像素游戏UI

### 具体改动
- 字体：使用 Google Fonts "Press Start 2P"（标题/数字）+ "Silkscreen"（正文）的 CDN
- 配色：保持暗色背景基调，加入像素绿、土黄、暖橙等自然色
- 边框/按钮：直角 + 双线边框模拟像素框，按钮带伪3D按下效果
- 装饰：简单像素图标（音符、乐器、心等用 emoji 或 CSS 绘制）
- 经验条：分段式像素进度条（小格填充而非平滑渐变）

## 五、文件结构

继续保持单文件 `index.html`，内联 CSS + JS：
- CSS 区按功能分块：基础/布局/像素主题/节拍器/结算画面/统计
- JS 区按功能分块：数据层/日历/节拍器/评分系统/结算画面/导航

所有数据存于 localStorage，key 前缀区分模块。
